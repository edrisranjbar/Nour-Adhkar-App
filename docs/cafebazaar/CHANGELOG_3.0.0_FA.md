# تغییرات نسخهٔ ۲.۵.۰

- پخش آیه‌به‌آیهٔ قرآن با ۳۱ قاری، نمایش آیهٔ در حال تلاوت و ورق‌خوردن خودکار صفحه؛ پخش آیات دریافت‌شده به‌صورت آفلاین.
- افزوده‌شدن زبان‌های دری و اردو، همراه با ترجمهٔ اردوی قرآن.
- مشخص‌شدن آیهٔ انتخاب‌شده در نتایج جست‌وجوی قرآن.
- ویجت اوقات شرعی خواناتر و قابل تغییر اندازه، و اعلان‌های کوتاه‌تر اذکار صبح و شام.
- نشان یخی تازه برای سپر هفتگی و بهبود چیدمان دکمه‌های نظر و پیشنهاد.
- رفع ایراد خروج با دو بار زدن دکمهٔ بازگشت و بهبود رابط کاربری.
