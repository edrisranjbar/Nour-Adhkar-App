# تغییرات نسخهٔ ۳.۰.۰

- افزودن زبان کوردی (سورانی) همراه با ترجمهٔ کوردی قرآن
- اضافه شدن «دعای پس از اذان» و «دعای نماز جنازه» و امکان دریافت اذکار جدید بدون به‌روزرسانی برنامه
- ادامهٔ پخش تلاوت قرآن در پس‌زمینه با کنترل از اعلان و صفحهٔ قفل، و طراحی تازهٔ صفحهٔ پخش صوت
- ثبت استمرار با تیک زدن چک‌لیست از ویجت صفحهٔ اصلی و اصلاح نتایج جستجو
- رفع مشکلات موقعیت‌یابی و انتخاب شهر، حتی بدون اینترنت
