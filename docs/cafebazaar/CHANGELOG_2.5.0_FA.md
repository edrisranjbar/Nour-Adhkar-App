# تغییرات نسخهٔ ۲.۵.۰

- پخش آیه‌به‌آیهٔ قرآن در صفحهٔ قرآن: آیهٔ در حال تلاوت رنگی می‌شود و صفحه همراه تلاوت ورق می‌خورد.
- دکمهٔ «پخش از این آیه» در پنل هر آیه.
- نوار پخش شناور با نام سوره، شمارهٔ آیه و قاری، همراه با آیهٔ قبل و بعد، مکث و بستن.
- ۳۱ قاری برای پخش آیه‌به‌آیه، از جمله الحصری (معلم)، المنشاوی و عبدالباسط (مرتل و مجوّد)، شهریار پرهیزگار و کریم منصوری.
- نگهداری آیه‌های شنیده‌شده برای پخش دوباره بدون اینترنت.
- زبان دری (افغانستان) با نام ماه‌های حمل تا حوت و واژه‌های رایج دری.
- اعلان‌های کوتاه‌تر برای اذکار صبح و شام، همراه با نماد خود برنامه.
