# Version 1.3.0 Changes

- Added a navigation drawer for quicker access to app sections
- Added Favorites for saving selected adhkar
- Created a separate “Duas & Supplications” section for Quranic and authentic Sunnah duas
- Added 15 practical daily-situation adhkar categories covering waking, clothing, meals, home, mosque, prayer, and travel
- Separated the supplications for entering and leaving the bathroom
- Added Arabic text, Persian translations, and trusted references for the new adhkar
- Added a “Daily Obligations” checklist group with Fajr, Dhuhr, Asr, Maghrib, and Isha as separate items
- Separated daily obligations from recommended deeds and updated total daily progress
- Records each completed adhkar collection as one history entry, without individual or duplicate entries
- Unified the tasbih icon between the navigation drawer and bottom navigation
- Corrected the app-sharing text and open-source project title
- Improved navigation, stability, and the overall user experience
