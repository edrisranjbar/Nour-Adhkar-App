# Version 2.4.0 changes

- New Quran audio section with 50 reciters, searchable Surah and reciter selection, and a cover displaying the reciter’s name.
- Pause/resume, seeking, 10-second skips, and playback speed controls.
- Recitations download on first playback and remain available offline, preserving existing downloads.
- Improved progress sync with automatic session renewal and clearer error messages.
- Jalali date and Persian digits for the last sync time in the Persian profile.
