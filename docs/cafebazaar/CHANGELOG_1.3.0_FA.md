# تغییرات نسخه ۱.۳.۰

- افزودن منوی کشویی برای دسترسی سریع‌تر به بخش‌های برنامه
- افزودن بخش علاقه‌مندی‌ها برای ذخیره اذکار منتخب
- ایجاد بخش مستقل «دعا و نیایش» برای دعاهای قرآنی و دعاهای مأثور از سنت رسول (ص)
- افزودن ۱۵ دسته کاربردی برای اذکار موقعیت‌های روزانه؛ از بیدارشدن و پوشیدن لباس تا غذا، خانه، مسجد، نماز و سفر
- جداسازی دعای ورود به سرویس بهداشتی از دعای خروج از آن
- افزودن متن عربی، ترجمه فارسی و منبع معتبر برای اذکار جدید
- افزودن گروه «فرائض روزانه» به چک‌لیست با نمازهای صبح، ظهر، عصر، مغرب و عشاء به‌صورت جداگانه
- تفکیک فرائض روزانه از اعمال مستحب در چک‌لیست و محاسبه مجموع پیشرفت روز
- ثبت هر مجموعه اذکار به‌صورت یک رکورد کامل در تاریخچه و جلوگیری از ثبت ذکرهای منفرد یا رکورد تکراری
- یکسان‌سازی آیکون تسبیح‌شمار در منوی کشویی و نوار پایین
- اصلاح متن اشتراک‌گذاری برنامه و عنوان پروژه متن‌باز اذکار نور
- بهبود ناوبری، پایداری و تجربه کاربری
