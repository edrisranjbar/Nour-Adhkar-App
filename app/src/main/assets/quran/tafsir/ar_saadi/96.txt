1|هذه السورة أول السور القرآنية نزولًا على رسول الله صلى الله عليه وسلم.فإنها نزلت عليه في مبادئ النبوة، إذ كان لا يدري ما الكتاب ولا الإيمان، فجاءه جبريل عليه الصلاة والسلام بالرسالة، وأمره أن يقرأ، فامتنع، وقال: { ما أنا بقارئ } فلم يزل به حتى قرأ. فأنزل الله عليه: { اقْرَأْ بِاسْمِ رَبِّكَ الَّذِي خَلَقَ } عموم الخلق، ثم خص الإنسان.
2|وذكر ابتداء خلقه { مِنْ عَلَقٍ } فالذي خلق الإنسان واعتنى بتدبيره، لا بد أن يدبره بالأمر والنهي، وذلك بإرسال الرسول إليهم ، وإنزال الكتب عليهم، ولهذا ذكر بعد الأمر بالقراءة، خلقه للإنسان.
3|{ اقْرَأْ وَرَبُّكَ الْأَكْرَمُ } أي: كثير الصفات واسعها، كثير الكرم والإحسان، واسع الجود.
4|الذي من كرمه أن علم بالعلم و { عَلَّمَ بِالْقَلَمِ}
5|[عَلَّمَ الْإِنْسَانَ مَا لَمْ يَعْلَمْ } فإنه تعالى أخرجه من بطن أمه لا يعلم شيئًا، وجعل له السمع والبصر والفؤاد، ويسر له أسباب العلم.فعلمه القرآن، وعلمه الحكمة، وعلمه بالقلم، الذي به تحفظ به العلوم، وتضبط الحقوق، وتكون رسلًا للناس تنوب مناب خطابهم، فلله الحمد والمنة، الذي أنعم على عباده بهذه النعم التي لا يقدرون لها على جزاء ولا شكور، ثم من عليهم بالغنى وسعة الرزق.
6|والإنسان -لجهله وظلمه- إذا رأى نفسه غنيًا، طغى وبغى وتجبر عن الهدى

8|ونسي أن إلى ربه الرجعى، ولم يخف الجزاء، بل ربما وصلت به الحال أنه يترك الهدى بنفسه، ويدعو [غيره] إلى تركه، فينهى عن الصلاة التي هي أفضل أعمال الإيمان.
9|يقول الله لهذا المتمرد العاتي: { أَرَأَيْتَ } أيها الناهي للعبد إذا صلى
11|{ إِنْ كَانَ } العبد المصلي { عَلَى الْهُدَى } العلم بالحق والعمل به،
12|{ أَوْ أَمْرٍ } غيره { بِالتَّقْوَى } .فهل يحسن أن ينهى، من هذا وصفه؟ أليس نهيه، من أعظم المحادة لله، والمحاربة للحق؟ فإن النهي، لا يتوجه إلا لمن هو في نفسه على غير الهدى، أو كان يأمر غيره بخلاف التقوى.
13|{ أَرَأَيْتَ إِنْ كَذَّبَ } الناهي بالحق { وَتَوَلَّى } عن الأمر، أما يخاف الله ويخشى عقابه؟
14|{ أَلَمْ يَعْلَمْ بِأَنَّ اللَّهَ يَرَى } ما يعمل ويفعل؟.
15|ثم توعده إن استمر على حاله، فقال: { كَلَّا لَئِنْ لَمْ يَنْتَهِ } عما يقول ويفعل { لَنَسْفَعَنْ بِالنَّاصِيَةِ } أي: لنأخذن بناصيته، أخذًا عنيفًا، وهي حقيقة بذلك.
16|فإنها { نَاصِيَةٍ كَاذِبَةٍ خَاطِئَةٍ } أي: كاذبة في قولها، خاطئة في فعلها.
17|{ فَلْيَدْعُ } هذا الذي حق عليه العقاب { نَادِيَهُ } أي: أهل مجلسه وأصحابه ومن حوله، ليعينوه على ما نزله به.
18|{ سَنَدْعُ الزَّبَانِيَةَ } أي: خزنة جهنم، لأخذه وعقوبته، فلينظر أي: الفريقين أقوى وأقدر؟ فهذه حالة الناهي وما توعد به من العقوبة.
19|وأما حالة المنهي، فأمره الله أن لا يصغى إلى هذا الناهي ولا ينقاد لنهيه فقال: { كَلَّا لَا تُطِعْهُ } [أي:] فإنه لا يأمر إلا بما فيه خسارة الدارين، { وَاسْجُدْ } لربك { وَاقْتَرَبَ } منه في السجود وغيره من أنواع الطاعات والقربات، فإنها كلها تدني من رضاه وتقرب منه.وهذا عام لكل ناه عن الخير ومنهي عنه، وإن كانت نازلة في شأن أبي جهل حين نهى رسول الله صلى الله عليه وسلم عن الصلاة، وعبث به وآذاه. تمت ولله الحمد.
