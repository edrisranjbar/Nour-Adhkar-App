## امکانات

- اذکار صبحگاه، شامگاه، روزانه، خواب، رمضان و استخاره
- متن عربی، ترجمه فارسی، منبع و شمارنده مرحله‌ای
- پخش صوتی صبحگاه و شامگاه با دریافت یک‌باره و پخش آفلاین
- تسبیح دیجیتال با امکان افزودن ذکر دلخواه و ثبت تاریخچه
- چک‌لیست روزانه و تقویم هفت‌روزه مداومت در اذکار و اعمال
- یادآور صبح و شام با انتخابگر واقعی ساعت ۲۴ ساعته
- حالت روشن و تاریک، تنظیم اندازه قلم، صدا و بازخورد لمسی
- اطلاع‌رسانی نسخه جدید و هدایت مستقیم به کافه‌بازار
- رابط کاملاً فارسی و راست‌به‌چپ؛ بدون تبلیغات، حساب کاربری یا ردیابی

## حریم خصوصی و آفلاین بودن

محتوا و امکانات اصلی برنامه آفلاین هستند. پیشرفت، تنظیمات، ذکرهای دلخواه و تاریخچه فقط روی دستگاه نگهداری می‌شوند. اینترنت صرفاً برای دریافت اولیه صوت و بررسی اختیاری نسخه جدید استفاده می‌شود. متن کامل در [سیاست حریم خصوصی](PRIVACY_POLICY_FA.md) موجود است.

## ساخت پروژه

پیش‌نیازها:

- Android Studio با JDK داخلی
- Android SDK 36
- Gradle Wrapper موجود در مخزن

```powershell
$env:JAVA_HOME='C:\Program Files\Android\Android Studio\jbr'
.\gradlew.bat assembleDebug
```

APK دیباگ در مسیر زیر ساخته می‌شود:

```text
app/build/outputs/apk/debug/app-debug.apk
```

اجرای تست‌ها:

```powershell
.\gradlew.bat testDebugUnitTest
```

## اطلاع‌رسانی نسخه جدید

برنامه فایل [`version.json`](version.json) شاخه `main` را بررسی می‌کند. هنگام انتشار، `versionName` و `versionCode` این فایل باید هم‌زمان با نسخه کافه‌بازار به‌روزرسانی شوند. مقدار `minRequiredVersionCode` حداقل کد نسخهٔ مجاز را تعیین می‌کند؛ نسخه‌های برنامه‌ای که این قابلیت را دارند، اگر کد نصب‌شده پایین‌تر باشد، پیام به‌روزرسانی اجباری نمایش می‌دهند و تا به‌روزرسانی امکان بستن پیام یا ادامهٔ استفاده نیست. این مقدار را روی `versionCode` نسخه‌ای بگذارید که کاربران باید حداقل نصب کنند. برای نسخه‌های جدیدتر از حداقل تعیین‌شده، پیام به‌روزرسانی اختیاری است و کاربر می‌تواند آن را به بعد موکول کند. نسخه‌های قدیمی که هنوز از این فیلد پشتیبانی نمی‌کنند، فقط رفتار قبلیِ به‌روزرسانی اختیاری را دارند؛ بنابراین ابتدا نسخهٔ پشتیبان این قابلیت را منتشر کنید و در انتشار بعدی حداقل نسخه را افزایش دهید. نصب همچنان از طریق کافه‌بازار و با اقدام خود کاربر انجام می‌شود.
